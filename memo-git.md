# Mémo Git – Les commandes essentielles

## Commandes de Matou

- `git add` : prépare les fichiers modifiés pour le prochain commit.
- `git branch` : affiche les branches du projet.
- `git checkout` : permet de changer de branche.
- `git clone` : copie un dépôt GitHub sur son ordinateur.
- `git commit` : enregistre les modifications dans l'historique du projet.
