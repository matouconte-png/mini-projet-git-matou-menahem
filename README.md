# Mini-projet collaboratif GitHub

## Présentation du projet

Ce projet a pour objectif de mettre en pratique les commandes Git et les fonctionnalités de GitHub à travers un travail collaboratif en binôme.

Nous allons apprendre à créer des branches, effectuer des commits, envoyer nos modifications sur GitHub et utiliser les Pull Requests pour relire et fusionner notre travail.

## Les membres du binôme

- **Matou :** création de sa présentation personnelle et participation à la gestion du projet.
