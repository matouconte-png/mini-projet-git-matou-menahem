Présentation de Matou

Qui suis-je ?

Je m’appelle Matou, j’ai 18 ans et je suis étudiante. Je m’intéresse à l’informatique et au développement. J’aime découvrir de nouvelles choses dans le domaine du numérique et comprendre comment les outils informatiques fonctionnent.

À travers ce projet, je souhaite apprendre à utiliser Git et GitHub et à mieux comprendre le travail collaboratif.

Les 3 choses que j’ai apprises sur Git

1. Git permet de suivre les modifications effectuées dans un projet et de conserver son historique.
2. Les branches permettent de travailler séparément sans modifier directement la branche principale main.
3. Les commits permettent d’enregistrer les modifications à une étape précise du projet pour pouvoir retrouver son historique.
